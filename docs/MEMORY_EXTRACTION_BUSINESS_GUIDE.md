# 记忆抽取业务说明

这份说明给业务同学看，解释系统怎么用大模型从用户输入里抽取“个人信息、长期记忆、短期记忆”，以及业务系统应该怎么调用。

## 1. 业务系统怎么接入

业务系统只需要在用户对话后调用写入接口：

```http
POST /api/dialogue-memories
Content-Type: application/json
```

请求示例：

```json
{
  "ldapId": "liyu",
  "displayName": "李玉",
  "question": "我是李玉，今年35岁，我喜欢先看结论，今天临时要准备月度复盘。"
}
```

系统会做四件事：

1. 用 `ldapId` 找到或创建这个员工的记忆档案。
2. 把 `question` 交给大模型，让模型识别里面有没有值得保存的个人记忆。
3. 大模型按三类记忆返回结构化 JSON。
4. 后端保存记忆，读取时返回一段简洁汇总文本。

读取接口：

```http
GET /api/dialogue-memories/{ldapId}
```

读取返回示例：

```json
{
  "ldapId": "liyu",
  "content": "个人基本信息：我是李玉，今年35岁；长期记忆：我喜欢先看结论；临时记忆：最近 5 天关注：今天临时要准备月度复盘；"
}
```

## 2. 三类记忆是什么意思

| 类型 | 系统字段 | 适合保存什么 | 例子 |
|---|---|---|---|
| 个人基本信息 | `profile` | 姓名、年龄、岗位、部门、联系方式等稳定身份信息 | `我是李玉，今年35岁`、`我在销售部` |
| 长期记忆 | `long_term` | 长期偏好、工作习惯、稳定背景 | `我喜欢先看结论`、`我偏好中文简洁摘要` |
| 短期记忆 | `temporary` | 当前任务、近期关注事项、阶段性上下文 | `今天临时要准备月度复盘`、`这周关注供应商风险` |

短期记忆只保留最近 5 天的汇总，超过 5 天的短期内容会删除，避免越积越乱。

## 3. 当前真实大模型提示词

系统当前给大模型的提示词如下：

```text
从以下员工输入中抽取个人记忆。只返回 JSON 数组，
每项包含 content、layer、memory_type、confidence。不要返回解释文字。
如果一句话里同时包含姓名、部门、偏好、当前任务等多个事实，必须拆成多条记忆，不要合并或遗漏。
content 必须保留关键实体原文，例如姓名、部门、岗位、偏好对象。
layer 只能是 profile、long_term、temporary。
profile 用于姓名、岗位、部门、联系方式等个人基本信息；
long_term 用于长期偏好、工作习惯、稳定背景；
temporary 用于短期上下文、当前任务、阶段性状态。
```

这段提示词的重点是：

- 只返回 JSON，不返回解释文字，方便后端直接保存。
- 一句话里有多个事实时必须拆开，例如姓名、年龄、偏好、当前任务要拆成多条。
- `layer` 只能从 `profile`、`long_term`、`temporary` 三个值里选。
- `content` 要保留原文里的关键实体，不能改写到看不出用户原话。

## 4. 具体抽取例子

用户输入：

```text
我是李玉，今年35岁，我喜欢先看结论，今天临时要准备月度复盘。
```

大模型应该抽取为：

```json
[
  {
    "content": "我是李玉，今年35岁",
    "layer": "profile",
    "memory_type": "profile",
    "confidence": 0.95
  },
  {
    "content": "我喜欢先看结论",
    "layer": "long_term",
    "memory_type": "preference",
    "confidence": 0.9
  },
  {
    "content": "今天临时要准备月度复盘",
    "layer": "temporary",
    "memory_type": "context",
    "confidence": 0.85
  }
]
```

业务系统读取时不需要关心数据库里的多条记录，只看汇总结果：

```text
个人基本信息：我是李玉，今年35岁；长期记忆：我喜欢先看结论；临时记忆：最近 5 天关注：今天临时要准备月度复盘；
```

## 5. 哪些内容不会保存

系统会过滤明显不是记忆的问题，例如：

- `我是谁`
- `你知道我是谁吗`
- `我叫什么`
- `我多大`

这些是用户在“问问题”，不是在提供新事实，所以不会作为记忆保存。

## 6. 业务同学怎么判断一句话该不该抽取

可以用一个简单判断：

- 如果这句话描述了“这个人是谁、喜欢什么、正在做什么”，通常可以抽取。
- 如果这句话只是普通提问，例如“我是谁”“帮我查一下”，通常不保存。
- 如果内容只在最近几天有用，放短期记忆。
- 如果内容长期稳定有用，放个人信息或长期记忆。
